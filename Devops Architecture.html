Change 1 thing first: replace YOUR_DOCKERHUB_USERNAME with your real Docker Hub username.

groovy
pipeline {
  agent any

  environment {
    IMAGE      = "YOUR_DOCKERHUB_USERNAME/flask-app"
    TAG        = "${BUILD_NUMBER}"
    APP_SERVER = "43.204.233.3"
  }

  stages {
    stage('Checkout') {
      steps {
        git branch: 'main', url: 'https://github.com/Disha-Patil02/devops-mini-project.git'
      }
    }

    stage('Build Image') {
      steps {
        sh "docker build -t ${IMAGE}:${TAG} -t ${IMAGE}:latest ./app"
      }
    }

    stage('Push to Docker Hub') {
      steps {
        withCredentials([usernamePassword(credentialsId: 'dockerhub-creds',
                          usernameVariable: 'DH_USER', passwordVariable: 'DH_PASS')]) {
          sh 'echo "$DH_PASS" | docker login -u "$DH_USER" --password-stdin'
          sh "docker push ${IMAGE}:${TAG}"
          sh "docker push ${IMAGE}:latest"
        }
      }
    }

    stage('Deploy to App Server') {
      steps {
        withCredentials([sshUserPrivateKey(credentialsId: 'app-server-key',
                          keyFileVariable: 'KEY', usernameVariable: 'SSH_USER')]) {
          sh """
            ssh -o StrictHostKeyChecking=no -i \$KEY \$SSH_USER@${APP_SERVER} '
              docker pull ${IMAGE}:${TAG};
              docker rm -f flask-app || true;
              docker run -d --name flask-app --restart always -p 5000:5000 ${IMAGE}:${TAG}
            '
          """
        }
      }
    }

    stage('Health Check') {
      steps {
        sh "sleep 5 && curl -f http://${APP_SERVER}:5000"
      }
    }
  }

  post {
    always {
      sh 'docker logout || true'
    }
  }
}

Keep ☑ Use Groovy Sandbox ticked, click Save, then Build Now.

Two things to know

  1. The Checkout stage still pulls your code from GitHub, so the repo must have your files. If GitHub is still empty, this stage will fail. Fix the push first.
  2. “Pipeline script from SCM” is the better option once GitHub works. Then Jenkins reads the Jenkinsfile from your repo, and any change you push to it is picked up automatically. Interviewers expect it done that way.

When the build finishes, open http://43.204.233.3:5000 to see your app. If any stage turns red, go to #1 → Console Output and send me the error.
